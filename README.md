# House Rental System — C++

Academic Programming Fundamentals final project. Console-based property listing, booking simulation, rent calculation, and administrator operations.

## Source

The original C++ implementation is being migrated from the Programming Fundamentals lab repository. This is an **academic prototype**, not a production property rental service.

## Run

```bash
g++ -std=c++11 src/main.cpp -o house-rental
./house-rental
```

On Windows, run `house-rental.exe` after compiling.

> Demo-only authentication or sample contract text must not be used in production. No real financial transactions or persistent bookings are implied.
